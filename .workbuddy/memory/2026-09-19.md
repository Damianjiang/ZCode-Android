# 2026-09-19 Work Log

## ZCode Android 聊天加载卡住问题修复

### 诊断过程
- 从远程 https://zcode.z.ai/remote/v4 获取完整前端代码 (index-nOVzQNKW.js ~4.8MB)
- 分析 Web 客户端 conversation 订阅、frame 组装、超时机制
- 对比 Android Kotlin 协议栈的实现差异

### 根因
1. **Bridge 降级无超时恢复** - Android 的 BridgeSession 在收到 bridge-degraded 事件后启动恢复，但无超时保护；若服务器响应慢或中断，会无限等待
2. **帧组装无超时清理** - RpcFrameTransport 的 assemblies map 只增不减，大量历史消息的未完成组装会永久占用内存并阻塞新消息
3. **重连超时过短** - 原 30s 超时对大 workspace 不够用

### 修复方案
1. **BridgeSession.kt** - 添加 staleTimer (45s)，监测无帧到达时触发恢复
2. **RpcFrameTransport.kt** - 添加 ASSEMBLY_TIMEOUT_MS=5s，周期性清理过期组装
3. **ZemoteClient.kt** - 超时增至 60s，添加重试退避 (250ms/1s/3s)，防止并发 reopen
