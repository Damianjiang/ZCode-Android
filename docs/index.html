下载方式

点击上方下载按钮获取 Release APK，或访问 GitHub Releases 页面。

→ 访问 GitHub Releases

克隆整个项目源码：

git clone https://github.com/Damianjiang/ZCode-Android.git

⚠️ 注意：不支持 SSH Key 方式 git clone

使用命令行工具下载 Release APK：

# wget
wget https://github.com/Damianjiang/ZCode-Android/releases/download/v1.9.4/app-release.apk

# curl
curl -O https://github.com/Damianjiang/ZCode-Android/releases/download/v1.9.4/app-release.apk
