⚡ 流式实时渲染

思考过程逐字增量显示，不再等思考完成后整段弹出。

🤖 子智能体管理

工具调用卡片一键进入只读子会话，返回自动恢复父会话。

🔐 权限审批

完整支持 permission_request / elicitation_request，手机端直接审批。

📋 任务面板

实时显示后台运行任务与待审批交互，支持一键终止。

🔍 调试日志

记录所有协议请求/响应，支持一键复制反馈给开发者。

🗑️ 缓存管理

设置页可单独清除会话缓存和调试日志，释放存储空间。
