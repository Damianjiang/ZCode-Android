流式实时渲染

思考过程（reasoning）逐字增量显示，不再等思考完成后整段弹出。自动跟随滚动，阅读丝滑。

🤖

子智能体管理

工具调用卡片内置「查看子智能体」入口，进入只读子会话，返回自动恢复父会话状态。

🔐

权限审批

完整支持 permission_request / elicitation_request，在手机上直接审批文件或执行命令。

📋

任务面板

实时显示后台运行任务、待审批交互，支持一键终止，信息一目了然。

🔍

调试日志

记录所有协议请求/响应与用户操作，支持一键复制反馈，方便定位问题。

🗑️

缓存管理

设置页可单独清除会话桥接缓存和调试日志，释放存储空间。
